طريقة التشغيل

1. تشغيل بوت تيليجرام (Python)

يتطلب وجود Python مثبت على جهازك. قم بتنفيذ الأوامر التالية:

pip install python-telegram-bot
python Automation-Bots/tgbot.py

2. تشغيل بوت واتساب (Node.js)

يتطلب وجود Node.js. قم بتنفيذ الأوامر التالية في مجلد المشروع:

npm install @whiskeysockets/baileys pino readline
node Automation-Bots/WatsBot.js

هل تحتاج إلى بوت مخصص لنشاطك التجاري؟

تواصل معي مباشرة لمناقشة مشروعك وتحويل أفكارك إلى واقع.
